# Klyppr releases

Official installers and automatic updates for [Klyppr](https://klyppr.com), the
desktop app that turns livestream moments into vertical shorts.

**Download Klyppr at [klyppr.com/download](https://klyppr.com/download).**

- Windows installers are signed by **Klyppr LLC**. If Windows shows "Windows
  protected your PC", choose **More info**, check that the publisher reads
  Klyppr LLC, then **Run anyway**.
- The installed app keeps itself up to date from this page; you don't need to
  download new versions by hand.

This repository holds release files only. Support: support@klyppr.com
